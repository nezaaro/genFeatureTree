# genFeatureTree

Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.1.

## Requirements

- Roblox Studio
- Visual Studio Code
- Node.js (LTS)
- Git
- Rokit
- Rojo (latest version!)

## Getting Started

1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd genFeatureTree
```

2. Install Node.js dependencies

```bash
npm install
```

3. Install development tools

```bash
rokit install
```

4. Generate the Rojo project tree

```bash
npm run generate
```

5. Start automatic tree generation

```bash
npm run watch
```

6. Start Rojo
   In another terminal:

```bash
rojo serve default.project.json
```

Connect to the running Rojo server through the Roblox Studio plugin.
